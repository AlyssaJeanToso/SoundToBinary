08 / EXPLAIN IT

What I Learned

Sampling: For me, sampling means taking small points from a sound wave to measure it.

Quantization: I learned that quantization changes sample values into numerical levels.

Binary: Binary uses only 0 and 1 to represent digital information.

IMPORTANT NOTES

What I Noticed

  • Amplitude affects the height of the sampled wave.
  • More samples produce more points on the graph.
  • More bits provide more quantization levels.
  • The binary output changes when the settings change.
  • Digital sound can be represented using binary data.
